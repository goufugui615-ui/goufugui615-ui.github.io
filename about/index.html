关于本站

少女的茶话会 是一个二次元 AI 角色创作社区原型：把「出图配方」「角色卡」「自设故事」三种内容 用一个“角色”串起来。它同时也是一个前端框架练习项目。

三个分区

  • 配方馆：作品 + 可复现的结构化提示词，支持按角色 / 游戏 / 场景检索与一键复制。
  • 角色卡：角色设定、形象时间线、作品集与故事线的聚合页。
  • 自设故事：围绕角色展开的原创 / 同人写作，支持连载章节。

技术栈（当前原型）

层选型说明
框架Next.js 15（App Router）+ React 19静态导出，可部署到任意静态托管
样式原生 CSS 设计系统（app/globals.css）白底极简 + 二次元点缀，无 UI 框架依赖
数据JSON 种子数据（data/*.json）下一步迁移到 Supabase(Postgres)
图片public/img 本地静态资源正式版建议 R2 / OSS + WebP 三档尺寸

路线图

  1. 接入 Supabase：账号、点赞收藏、投稿入库与人工审核队列。
  2. 角色卡创建流程 + 图片上传（含自动压缩与 AI 标识水印）。
  3. 故事连载：章节管理、更新提醒、章节阅读进度。
  4. SEO：静态页 + 结构化数据 + sitemap，长尾词覆盖「角色名 + 提示词」。
  5. 社区运营：每周同款复现打卡、角色人气榜、创作活动。
